  • Defina horário exato para cada lembrete

  • Lista de todos os lembretes ativos

Perguntas frequentes

Por que não recebo as notificações?

O navegador precisa da sua permissão. Na primeira vez ele pergunta, e você deve escolher permitir. A página também precisa estar aberta.

Os lembretes se repetem todos os dias?

Sim, o lembrete dispara no horário marcado a cada dia.

O lembrete funciona mesmo com o navegador fechado?

Se o navegador estiver aberto, você recebe a notificação no horário marcado. Com o navegador fechado, o lembrete aparece quando você abrir o app novamente.

Posso criar lembretes recorrentes?

No momento cada lembrete é único. Você pode criar novos lembretes para datas diferentes.

Como começar

Clique no botão acima para abrir o OrganizaJá já na ferramenta de Lembretes. Não precisa criar conta, não precisa baixar nada e não tem versão paga. Tudo que você registrar fica salvo no seu próprio aparelho, então seus dados continuam privados.
