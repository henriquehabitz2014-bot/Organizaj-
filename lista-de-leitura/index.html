O que essa ferramenta faz

  • Livros separados entre quero ler, lendo e lido

Perguntas frequentes

Serve para meta de leitura do ano?

Serve muito bem. Combine com a ferramenta de Metas para acompanhar o número de livros do ano.

Dá para anotar quantas páginas li?

O foco é o acompanhamento por livro, mas você pode usar as Notas para detalhes.

Como começar

Clique no botão acima para abrir o OrganizaJá já na ferramenta de Leitura. Não precisa criar conta, não precisa baixar nada e não tem versão paga. Tudo que você registrar fica salvo no seu próprio aparelho, então seus dados continuam privados.
